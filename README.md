# 🦊 MultiTimer

Компактный многофункциональный таймер для игр, стримов и работы.

## Особенности

- ✅ Поверх всех окон
- ✅ Перетаскивание и изменение размера
- ✅ Таймеры и секундомеры
- ✅ Быстрое добавление (Ctrl+1...9, Ctrl+0, Ctrl+H)
- ✅ Две темы (тёмная/светлая)
- ✅ Два языка (RU/EN)
- ✅ Персонализация (цветовые полоски)
- ✅ Настройка прозрачности
- ✅ Бесплатно навсегда
